- **Κανόνας (Β2):** άρνηση `vehicle_clear_use_clear` μόνο όταν (α) φορτηγό, οδηγός, ρυμουλκούμενο ή συνεργάτης που **υπάρχει τώρα** θα γινόταν `null` στον ίδιο τύπο κύκλου, ή (β) κύκλος που είχε όχημα (φορτηγό ή συνεργάτη) θα γινόταν OWNED χωρίς φορτηγό (και με αλλαγή τύπου).
