## ΒΗΜΑ 5 — Migration `locations` ⛔ ΘΕΛΕΙ ΕΓΚΡΙΣΗ

Νέες στήλες: `notes`, `tags`, `phone`/`contact`, **`type_raw`**.

**Το `type_raw` πρώτο και ΠΑΝΤΑ:** αντιγραφή ΟΛΩΝ των τιμών του `type` πριν
αγγιχτεί οτιδήποτε. Η αναστροφή γίνεται με ένα `UPDATE locations SET type =
type_raw`. Χωρίς αυτό δεν ξεκινά τίποτα (αρχή 7).

Κανονικοποίηση των **228** διακριτών τιμών (612 κενές μένουν κενές):
- **Αυτόματα:** `NOTES : *` → `notes` αυτούσιο· `CLIENT ?: X` → tag, με την

  έγκριση**, όχι με regex.
- **ΟΧΙ αυτόματα:** τιμές με ≥3 συνεχόμενα ψηφία (τηλέφωνα/διευθύνσεις — μόνο
  ~4 γραμμές, με το χέρι)· πολλοί πελάτες σε μία τιμή (`CLIENT : GLOBAL, KMG`)·
  ελεύθερο κείμενο χωρίς πρόθεμα → πάει αυτούσιο σε `notes`, το `type` αδειάζει.

**Ο owner ενέκρινε αυτόματη μεταφορά + κανονικοποίηση, ΜΕ λίστα αντιστοίχισης
προς έγκριση πριν εκτελεστεί.** Παρήγαγε τη λίστα πρώτα.

## 🔄 ΑΛΛΑΓΗ ΣΧΕΔΙΑΣΗΣ 1 — το tag πελάτη είναι ΠΑΡΑΓΟΜΕΝΟ, όχι καταχωρημένο

**Owner:** «η ομαδοποίηση των locations ανά πελάτη θα γίνεται **αφότου
καταχωρούνται παραγγελίες**, άρα θα είναι μια **συνεχής διεργασία**».

Αυτό ΔΕΝ είναι χειροκίνητο πεδίο που κάποιος συντηρεί. Είναι **παράγωγο των
παραγγελιών, που ανανεώνεται μόνο του**.

Επαληθεύτηκε ότι είναι εφικτό **χωρίς κανένα κενό**:

```sql
COALESCE(order_stops.client_at_stop_id, orders.client_id, national_orders.client_id)
-- 267 στάσεις / 267 με πελάτη / 0 χωρίς / 111 τοποθεσίες
```

**Συνέπειες για το Βήμα 5:**
- Το tag πελάτη **δεν καταχωρείται**. Παράγεται από τις στάσεις και δείχνεται
  στην κάρτα ως μέτρηση με ημερομηνίες: «OGL 12× (τελ. 20/08)».
- Η αναζήτηση «τοποθεσίες του πελάτη Χ» χτίζεται πάνω στο παράγωγο — άρα είναι
  **σωστή από την πρώτη μέρα** και μένει σωστή χωρίς συντήρηση.
- Η κανονικοποίηση του `type` **εξακολουθεί να χρειάζεται**, αλλά ο ρόλος της
  αλλάζει: όχι για να στήσει τα tags (τα δίνουν τα δεδομένα) αλλά για να
  **ξεβουλώσει** το πεδίο — τα `CLIENT : X` γίνονται ιστορικό/`type_raw`, τα
  `NOTES :` και το ελεύθερο κείμενο πάνε σε `notes`, το `type` κρατά **μόνο**
  δομημένο λεξιλόγιο (~7 τιμές: Client Depot, Fuel Station, Partner Warehouse,
  ΣΥΝΕΡΓΕΙΟ, Custom Point, Veroia Hub, πλυντήριο).
- Η στήλη `tags` παραμένει — αλλά για ό,τι **ΔΕΝ** ξέρουν τα δεδομένα (π.χ.
  «χωρίς κλαρκ», «τηλεφώνησε πριν»). Όχι για πελάτες.

⚠️ Ο κίνδυνος αν αγνοηθεί: χειροκίνητο tag πελάτη = τρίτη λίστα που αποκλίνει
(**αρχή 3**). Οι δύο πρώτες υπάρχουν ήδη — το `type` και οι παραγγελίες.
