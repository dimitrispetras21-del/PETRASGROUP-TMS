# Κατάλογος περιπτώσεων για το απόλυτο sync v6 (r2)

Κάθε γραμμή είναι περίπτωση του τεστ (PLAN §Γ2).

**Σύμβολα:**
- `E` = εξαγωγή, `I` = εισαγωγή, `G` = μέλος ομάδας, `R` = ρότα, `L1` / `L2` = σκέλη σπασμένης παραγγελίας·
- `T1` / `T2` = φορτηγά, `D1` / `D2` = οδηγοί, `P1` = συνεργάτης·
- `Ρ`, `Ρ'` = δρομολόγια του S0, που κρατούν τον κωδικό τους στη σύγκριση.

**Ενέργειες:**
- `assign` / `unassign` / `match` / `unmatch` / `join` / `leave` / `dissolve` / `rota+` / `rota-` / `split` / `rejoin` / `reorder` = οι RPC μίας κίνησης (PLAN §Β2)·
- `form:x` = απλή PATCH από φόρμα / Daily Ops·
- `drain` = εκκένωση ουράς.

**«Σειρά: όλες»** = κάθε μετάθεση των ενεργειών, με drain μετά από κάθε βήμα **και** μόνο στο τέλος· όλα δίνουν το ίδιο.

**Κανόνας** = Q1–Q8 (4/10), N1–N12 (PLAN §4, προτάσεις), ή PLAN §Β2 / §Β3.
