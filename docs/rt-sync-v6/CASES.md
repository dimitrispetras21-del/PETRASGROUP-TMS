# Κατάλογος περιπτώσεων για το απόλυτο sync v6

Κάθε γραμμή είναι μια περίπτωση του τεστ ιδιοτήτων (PLAN §Γ2).
- **Σύμβολα:** `E` = εξαγωγή, `I` = εισαγωγή, `G` = μέλος ομάδας, `R` = ρότα, `T1` / `T2` = φορτηγά, `D1` / `D2` = οδηγοί, `P1` = συνεργάτης.
- **Εγγραφές:** «link» = `matched_import_id` / `group_id` / `rotation_id`, «veh» = φορτηγό, «unveh» = αφαίρεση φορτηγού. Κάθε εγγραφή είναι χωριστή συναλλαγή (όπως τα στέλνει η οθόνη).
- **Η στήλη «Σειρά»** λέει ποιες διατάξεις δοκιμάζονται: «όλες» = κάθε μετάθεση των εγγραφών, και όλες πρέπει να δίνουν το ίδιο `E`.
- **«Κανόνας»:** η απάντηση owner (Q1–Q8) ή ο κανόνας του PLAN §Β2 που ορίζει το αποτέλεσμα. **«N#»** = ανοιχτή ερώτηση· το αποτέλεσμα γράφει την πρόταση.

## Νέα ερώτηση που προέκυψε από τον κατάλογο
- **N8.** Ταίριασμα εισαγωγής που είναι ανατεθειμένη σε **συνεργάτη** με εξαγωγή του δικού μας στόλου (ή το αντίστροφο). Πρόταση: όπως το N1, η εισαγωγή παίρνει το όχημα της εξαγωγής και η ανάθεση συνεργάτη φεύγει (το κόμιστρο, αν υπάρχει, «θέλει έλεγχο»). Αν η εισαγωγή έχει ήδη εκτελεστεί, κρατά τον συνεργάτη.
