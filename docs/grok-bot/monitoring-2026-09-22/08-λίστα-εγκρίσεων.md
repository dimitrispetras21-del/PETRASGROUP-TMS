# 08 — Λίστα εγκρίσεων: 20 συγκεκριμένες αλλαγές, μία-μία με ναι/όχι

Καμία γενική ερώτηση «να προχωρήσω;». Κάθε γραμμή λέει **τι ακριβώς αλλάζει** (αρχείο / πίνακας / ρύθμιση),
**ποιος το εκτελεί**, **τι ρισκάρει**, **πώς αναιρείται**, **τι κοστίζει**. Ο ιδιοκτήτης απαντά ανά γραμμή.
Συμπληρώνει το `12-εγκρίσεις.md` — δεν το αντικαθιστά· όπου υπάρχει ήδη γραμμή εκεί, σημειώνεται.

**Κανόνες που ισχύουν σε κάθε «ναι»:** εκτέλεση σε βάση ή Worker **μόνο μετά τις 15:00**· deploy Worker **μόνο**
με τον φρουρό των τριών πριν και μετά· κάθε αλλαγή κώδικα περνά από branch → ελεγκτή → `main`· **το repo είναι
δημόσιο** — κανένα εύρημα ασφαλείας δεν ανεβαίνει πριν κλείσει.

## Σειρά που προτείνεται

`E-01…E-04` (προαπαιτούμενα, μηδέν ρίσκο) → **`E-05` + `E-06`** (η εγκατάσταση) → **`E-07`** (οι δοκιμές — η
πύλη· χωρίς αυτές δεν προχωράμε) → `E-11` (Cloudflare, ανεξάρτητο και γρήγορο) → `E-08` + `E-09` (ένα deploy)
→ `E-10` → `E-17` → `E-12` → Κύμα 3. Τα `E-13`, `E-14`, `E-15`, `E-16`, `E-18`, `E-19`, `E-20` όποτε υπάρχει
χρόνος — **εκτός από το `E-19`, που μπλοκάρει σιωπηλά τα πάντα όσο μένει ανοιχτό**.

## Τι ΔΕΝ ζητείται σε αυτή τη λίστα
Καμία αλλαγή σε δικαιώματα ρόλων της εφαρμογής, καμία διόρθωση δεδομένων, καμία διαγραφή, κανένα νέο πεδίο
οθόνης, καμία αλλαγή στα κλειδωμένα του `CLAUDE.md`. Οι ουρές εργασίας (63 στην πύλη παλετών, 58 ατιμολόγητες
> 30 ημερών, 23 ανοιχτοί γύροι, 160 γραμμές χωρίς δρομολόγιο) **δεν** είναι αίτημα έγκρισης — είναι δουλειά
ανθρώπων και εμφανίζονται ως νούμερα στην πρωινή σύνοψη.
