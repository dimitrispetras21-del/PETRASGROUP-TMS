αποδεικνύει ενεργή κάλυψη — άρα **η ασφάλεια ανανεώθηκε, το PDF δεν ανέβηκε**.

παρακολουθεί μόνο ΚΤΕΟ/ΚΕΚ/ασφάλεια — **η οδική βοήθεια και ο ταχογράφος
