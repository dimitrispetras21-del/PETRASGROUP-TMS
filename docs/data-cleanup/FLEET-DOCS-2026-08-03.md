1. **Το TMS είναι μπαγιάτικο, όχι ο στόλος.** Και τα 4 οχήματα έχουν ΚΤΕΟ σε
   ισχύ (2026-2027) ενώ το TMS τα δείχνει κόκκινα. Τα «37 ληγμένα έγγραφα»
   είναι κατά κύριο λόγο **μη ενημερωμένες εγγραφές**.
2. **⚠️ Πραγματικό κενό ασφάλισης:** IAB2108 και IAB2106 — το νεότερο
   ασφαλιστήριο στον φάκελο λήγει **31-12-2025** (πέρασε), ενώ η πράσινη κάρτα
   τους φτάνει ως 31-12-2026. Είτε δεν ανέβηκε η ανανέωση, είτε υπάρχει
   πραγματικό κενό. **Χρειάζεται έλεγχος σήμερα.**
3. Η μπλε κάρτα λήγει **12-12-2030** σε όλα — κοινή ημερομηνία, χαμηλή προτεραιότητα.
4. Τα ονόματα αρχείων είναι **αξιόπιστη πηγή ημερομηνιών** σε όλους τους
