## 🔴 Το βασικό πρόβλημα του φύλλου: ασυνεπής μορφή ημερομηνίας

Το ίδιο κελί μπορεί να είναι `M/D/YYYY` ή `D/M/YYYY` **χωρίς κανόνα**. Στη
βουλγάρικη ενότητα η ίδια ημερομηνία γράφεται και στις δύο μορφές δίπλα-δίπλα:

```
CB5284ΤΡ   ΚΤΕΟ 11/19/2026   ΚΕΚ 19/11/2026    ← ίδια μέρα, δύο μορφές
CB4612PE   ΚΤΕΟ 8/28/2026    ΚΕΚ 28/8/2026
CB0142HO   ΚΤΕΟ 5/29/2027    ΚΕΚ 29/5/2027
```

Όσο το φύλλο μένει έτσι, **κάθε αυτόματος συγχρονισμός θα εισάγει λάθη**. Αν
πρόκειται να γίνει μαζική ενημέρωση, η μορφή πρέπει πρώτα να ενοποιηθεί
(προτεινόμενο: ISO `YYYY-MM-DD` σε όλα τα κελιά).
