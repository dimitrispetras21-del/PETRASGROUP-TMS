## Κανόνας

Μία εγγραφή ανά **απόφαση**, όχι ανά commit. Απόφαση = κάτι που θα μπορούσε
εύλογα να είχε γίνει αλλιώς. Μορφή:

```
### YYYY-MM-DD · <περιοχή> · <η απόφαση σε μία γραμμή>
**Επιλογή:** τι διαλέξαμε
**Εναλλακτικές:** τι απορρίφθηκε και γιατί
**Απόδειξη:** τι το στηρίζει (αρχείο:γραμμή, νούμερο, δοκιμή)
**Ποιος:** owner / Claude / και οι δύο
```

Αν κάτι ανατραπεί αργότερα **δεν σβήνεται** — μπαίνει νέα εγγραφή που δείχνει
πίσω. Η αλλαγή γνώμης είναι πληροφορία.

## 2026-08-12 — Παλέτες: typeahead αντί για select στη «Νέα κίνηση»
**Επιλογή**: Νέο `GET /pallets/lookups/search?type=party|clients|partners|locations&q=` (ilike + limit 20). Στη φόρμα, τα πεδία Αντισυμβαλλόμενος και Σημείο έγιναν typeahead (input + κρυφό id), με debounce 250ms και ελάχιστο 2 χαρακτήρες.

**Ποιος**: owner (επιλογή typeahead έναντι active-filter, 12/8).

## 28/8/2026 — Ο κριτής του redesign: καστάνια, HAR, και μια διαρροή

**Πλαίσιο:** χτίστηκε η αυτόματη σουίτα ελέγχων που θα φυλάει το app-wide redesign
(spec `docs/superpowers/specs/2026-08-28-app-redesign-graph-design.md`,
πλάνο `docs/superpowers/plans/2026-08-28-redesign-oracle.md`). Πέντε ουσιαστικές
αποφάσεις, όλες ληφθείσες κατά την εκτέλεση.

### 1. Καστάνια, όχι απόλυτοι κανόνες

**Επιλογή:** κάθε κριτής συγκρίνει με καταγεγραμμένο όριο ανά μονάδα, που **μόνο
πέφτει**. Όχι «μηδέν από σήμερα».

**Γιατί:** υπάρχουν 528 hex μέσα στα modules και 23 κελιά «άγνωστο ως μηδέν».
Απόλυτος κανόνας θα έβαφε κάθε μονάδα κόκκινη από την πρώτη μέρα, και **μια
σουίτα μονίμως κόκκινη αγνοείται μέσα σε μια βδομάδα**. Το όριο κάνει το χρέος
ορατό χωρίς να το μετατρέπει σε θόρυβο.

**Εναλλακτική που απορρίφθηκε:** απόλυτο μηδέν με λίστα εξαιρέσεων — η λίστα
γίνεται δεύτερη πηγή αλήθειας (αρχή 3).

**Απόδειξη:** κάθε κριτής παρατηρήθηκε να κοκκινίζει σε φυτεμένη παράβαση και να
επανέρχεται. Ο fan-in guard παρατηρήθηκε να κόβει με exit 2.

### 2. HAR αντί για αποθηκευμένο token

**Επιλογή:** οι ζωντανοί έλεγχοι τρέχουν με ψεύτικη συνεδρία στο `localStorage`
συν **ηχογραφημένη κίνηση δικτύου** που ξαναπαίζεται.

**Γιατί:** το JWT λήγει σε 8 ώρες. Αποθηκευμένο token σαπίζει σιωπηλά και οι
έλεγχοι αρχίζουν να «περνάνε» πάνω σε οθόνη σφάλματος — ακριβώς η σιωπηλή
αποτυχία που χτίζουμε για να αποφύγουμε. Και ο agent δεν αγγίζει ποτέ κωδικό.

**Παγίδα που βρέθηκε:** ο tamper guard του `core/auth.js` πετάει κάθε χρήστη που
λείπει από τη λίστα `USERS` του `index.html`. Χρησιμοποιούνται οι `demo_<ρόλος>`.

### 3. Το Stitch φεύγει από την αλυσίδα σχεδίασης

**Επιλογή:** η αλυσίδα της 26/8 (Stitch → Figma → MCP → κώδικας) γίνεται
**Figma → MCP → κώδικας**, με ενδιάμεσο βήμα απόδειξης πυκνότητας σε HTML με
πραγματικά δεδομένα.

**Γιατί:** το Stitch δεν σπρώχνει στο Figma — η ακμή του δεν κουβαλούσε τίποτα
δομημένο, μόνο εικόνα που κοιτάει άνθρωπος. Και οι κανόνες #5 (≥20 γραμμές) και
#6 (καμία κοπή επωνυμίας) είναι **ανέλεγκτοι** σε mockup με ψεύτικα δεδομένα.
