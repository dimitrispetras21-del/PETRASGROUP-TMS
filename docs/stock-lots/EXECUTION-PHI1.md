## Ζωντανός έλεγχος (βήμα 8) — σενάριο δοκιμής, χωρίς ίχνος στα χρήματα
- **Πώς:** ο διακόπτης ανοίγει **μόνο στην κονσόλα του συντονιστή** (`FEATURES.STOCK_LOTS = true`, χωρίς
  commit)· οι υπόλοιποι χρήστες δεν βλέπουν τίποτα.
- **Δεδομένα:** μία παραγγελία-δοκιμή με Reference `TEST-STOCK-…`, πελάτης δοκιμής, προορισμός μια
  τοποθεσία εξωτερικού, **χωρίς φορτηγό**, **χωρίς ανταλλαγή παλετών** — άρα κανένα RT, καμία μισθοδοσία,
  καμία κίνηση παλετών. **Καμία τιμολόγηση** στη δοκιμή.
- **Βήματα + απόδειξη στον πίνακα** (μετά από κάθε ενέργεια, το SELECT):
  1. Τικ «Παρτίδα» → αποθήκευση →
     `SELECT s.legacy_id, s.order_id, s.warehouse_charge, s.deleted_at FROM stock_lots s JOIN orders o ON o.id = s.order_id WHERE o.reference LIKE 'TEST-STOCK-%';` → 1 γραμμή, `deleted_at` NULL.
  2. Λωρίδα «ΑΠΟΘΕΜΑ» στο Weekly → η παρτίδα φαίνεται·
     `SELECT legacy_id, stock_pallets, remaining_pallets, complete FROM stock_v_lots WHERE reference LIKE 'TEST-STOCK-%';`
  3. (owner) «Χρέωση αποθήκης» 10 → `SELECT warehouse_charge FROM stock_lots WHERE legacy_id = '<rec>';` = 10.00·
     `SELECT allocation_status, charge_total, net FROM stock_v_lot_money WHERE lot_rec = '<rec>';`
  4. Ξετικάρισμα «Παρτίδα» → διαγραφή της παραγγελίας-δοκιμής.
- **Καθάρισμα — απόδειξη ότι δεν έμεινε τίποτα:**
  `SELECT count(*) FROM stock_lots s JOIN orders o ON o.id = s.order_id WHERE o.reference LIKE 'TEST-STOCK-%' AND s.deleted_at IS NULL;` = 0 ·
  `SELECT count(*) FROM ct_rt_legs l JOIN orders o ON o.id = l.order_id WHERE o.reference LIKE 'TEST-STOCK-%';` = 0 ·
  `SELECT count(*) FROM pl_movements m JOIN orders o ON o.id = m.order_id WHERE o.reference LIKE 'TEST-STOCK-%';` = 0.
  (Η άγκυρα `stock_lots` μένει ως soft delete — δεν υπάρχει hard delete, εκ σχεδιασμού.)

## Μετά την ενεργοποίηση — η πρώτη πραγματική τιμολόγηση παρτίδας (απόδειξη στον πίνακα)
Όταν η Ειρήνη τιμολογήσει την πρώτη παρτίδα:
`SELECT o.id, o.invoiced, o.invoice_number FROM orders o JOIN stock_lots s ON s.order_id = o.id WHERE s.legacy_id = '<rec>';` → `invoiced = true` και αριθμός·
`SELECT count(*) FROM orders WHERE stock_lot_id = (SELECT id FROM stock_lots WHERE legacy_id = '<rec>') AND invoiced;` = 0 (τα κομμάτια δεν τιμολογούνται ποτέ).

## Γνωστά μετά την ενεργοποίηση (όχι σφάλματα)
- **Παλέτες:** η παραλαβή παρτίδας γράφει μία εκκρεμή κίνηση με τον συνεργάτη· ο συνεργάτης-αποθήκη θα
  δείχνει «μας χρωστά Χ» μόνιμα (οι παλέτες φεύγουν πάνω στα κομμάτια) → ADJUSTMENT από την υπεύθυνη
  παλετών. Παρτίδα με δικό μας φορτηγό ή σημασμένη μετά την παράδοση → χειροκίνητη καταχώρηση.
- **Χρέωση αποθήκης:** την περνά μόνο ο owner· μένει ανοιχτή και μετά το τιμολόγιο. Ως τότε ο έλεγχος
  S-11 αναφέρει την παρτίδα («χωρίς χρέωση αποθήκης» / «λείπει το κόμιστρο συνεργάτη»).
- **Τιμή παρτίδας:** κλειδώνει με το τιμολόγιο πελάτη (διόρθωση = αναίρεση του «τιμολογήθηκε» πρώτα) —
  διαφορά από τις κανονικές παραγγελίες (043).
- **Αναίρεση παραλαβής σε παρτίδα συνεργάτη:** το «Undo» της γραμμής παίρνει την ανάθεση συνεργάτη, όχι
  την παραλαβή — η παρτίδα μένει «Στην αποθήκη ✓» (γνωστό, διορθώνεται μετά).
- **Ώρα:** μερικά όρια της βάσης μετρούν ημέρα UTC (διαφορά μόνο 00:00–03:00).
- **Ρόλος warehouse:** πριν ενεργοποιηθεί λογαριασμός, η cache του PDF εκτύπωσης θέλει τον ρόλο στο κλειδί.
