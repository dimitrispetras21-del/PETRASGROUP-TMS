# 02 — Baseline W20-22 + κόστος αλληλεπίδρασης (Β2+Β3)

Κατάσταση: **μοντέλο κλικ ολοκληρωμένο (Β3)** · μετρήσεις W20-22 σε εξέλιξη (Β2).

## Β3 — Κόστος ανά ροή (από τον κώδικα, `modules/weekly_intl.js`)

Μονάδες: κλικ (κ), πληκτρολόγηση (π), drag (d). Προϋπόθεση: η σωστή εβδομάδα
είναι ήδη ανοιχτή.

| Ροή | Βήματα | Κόστος |
|---|---|---|
| Ανάθεση σε δικό μας (μόνο truck) | pill (1κ) → Truck focus+επιλογή (2κ+π φίλτρου) → Save (1κ) | **4κ** |
| Ανάθεση πλήρης (truck+trailer+driver) | pill + 3×(focus+επιλογή) + Save | **8κ** |
| Ανάθεση σε συνεργάτη (χωρίς match) | pill + Company (2κ) + Plates (1κ+π) + Export Rate (1κ+π) + Save | **6κ + 2π** |
| Ανάθεση σε συνεργάτη (με match) | + Import Rate (1κ+π) — υποχρεωτικό (`:1465`) | **7κ + 3π** |
| Ταίριασμα import (χειροκίνητο) | σύρσιμο import row → export row | **1d** |
| Ταίριασμα (auto-match, αν λειτουργεί) | κουμπί (1κ) + confirm (1κ) για ΟΛΑ τα ζεύγη | **2κ** σύνολο |
| Αφαίρεση match | ✕ side-btn (1κ) | 1κ |
| Ομαδοποίηση 2 εξαγωγών | δεξί κλικ (1) + «Group with:» (1) | **2κ** |
| Ομαδοποίηση N εξαγωγών | (N-1)×2κ | 2κ·(N-1) |
| **Ξαναχτίσιμο ομάδας μετά από refresh** | ίδιο — η ομάδα δεν σώζεται (00 §2) | **×κάθε reload** |
| Αλλαγή ανάθεσης | ίδιο με ανάθεση (το popover προσυμπληρώνει) | 4-7κ |
| Καθαρισμός ανάθεσης | pill → Clear → confirm | 3κ |
| Εκτύπωση order / εβδομάδας | side-btn / κουμπί header | 1κ |
| Πλοήγηση ±1-3 εβδομάδες / μακρύτερα | 1κ / Nκ στο ‹ | 1κ / Nκ |
| Εντοπισμός γραμμής σε γεμάτη εβδομάδα | κλικ search + π (ή scroll) | 1κ+π |

**Τύπος τυπικής εβδομάδας** (συμπληρώνεται με όγκους W20-22):
`Κόστος ≈ E_own×4..8 + E_partner×6..7 + M×1d + G×2(N-1)×(1+R) + C×5..7`
όπου E=αναθέσεις ανά τύπο, M=matches, G=ομάδες, R=reloads που ξαναχάλασαν
ομάδα, C=αλλαγές. Το R είναι το κρυφό κόστος που δεν φαίνεται πουθενά.
