Κατάσταση: **Β2+Β3 ολοκληρωμένα** (μετρήσεις 6/8/2026, παραγωγικό, read-only —

## Β3 — Κόστος ανά ροή (από τον κώδικα, `modules/weekly_intl.js`)

Μονάδες: κλικ (κ), πληκτρολόγηση (π), drag (d). Προϋπόθεση: η σωστή εβδομάδα
είναι ήδη ανοιχτή.

| Ροή | Βήματα | Κόστος |
|---|---|---|
| Ανάθεση σε δικό μας (μόνο truck) | pill (1κ) → Truck focus+επιλογή (2κ+π φίλτρου) → Save (1κ) | **4κ** |
| Ανάθεση πλήρης (truck+trailer+driver) | pill + 3×(focus+επιλογή) + Save | **8κ** |
| Ανάθεση σε συνεργάτη (χωρίς match) | pill + Company (2κ) + Plates (1κ+π) + Export Rate (1κ+π) + Save | **6κ + 2π** |
| Ανάθεση σε συνεργάτη (με match) | + Import Rate (1κ+π) — υποχρεωτικό (`:1465`) | **7κ + 3π** |
| Ταίριασμα import (χειροκίνητο) | σύρσιμο import row → export row | **1d** |
| Ταίριασμα (auto-match, αν λειτουργεί) | κουμπί (1κ) + confirm (1κ) για ΟΛΑ τα ζεύγη | **2κ** σύνολο |
| Αφαίρεση match | ✕ side-btn (1κ) | 1κ |
| Ομαδοποίηση 2 εξαγωγών | δεξί κλικ (1) + «Group with:» (1) | **2κ** |
| Ομαδοποίηση N εξαγωγών | (N-1)×2κ | 2κ·(N-1) |
| **Ξαναχτίσιμο ομάδας μετά από refresh** | ίδιο — η ομάδα δεν σώζεται (00 §2) | **×κάθε reload** |
| Αλλαγή ανάθεσης | ίδιο με ανάθεση (το popover προσυμπληρώνει) | 4-7κ |
| Καθαρισμός ανάθεσης | pill → Clear → confirm | 3κ |
| Εκτύπωση order / εβδομάδας | side-btn / κουμπί header | 1κ |
| Πλοήγηση ±1-3 εβδομάδες / μακρύτερα | 1κ / Nκ στο ‹ | 1κ / Nκ |
| Εντοπισμός γραμμής σε γεμάτη εβδομάδα | κλικ search + π (ή scroll) | 1κ+π |

**Τύπος τυπικής εβδομάδας** (συμπληρώνεται με όγκους W20-22):
`Κόστος ≈ E_own×4..8 + E_partner×6..7 + M×1d + G×2(N-1)×(1+R) + C×5..7`
όπου E=αναθέσεις ανά τύπο, M=matches, G=ομάδες, R=reloads που ξαναχάλασαν
ομάδα, C=αλλαγές. Το R είναι το κρυφό κόστος που δεν φαίνεται πουθενά.

## Τι λένε τα νούμερα (είσοδος για 03/04)

1. **Το ταίριασμα σχεδόν δεν καταγράφεται.** 11 matched ζεύγη σε 46 imports (24%)
   σε 3 εβδομάδες. Είτε οι γύροι κανονίζονται εκτός συστήματος, είτε η ροή drag
   είναι ακριβή — η κεντρική υπόσχεση της σελίδας (όχι άδειος γυρισμός) δεν
   αποτυπώνεται. → ερώτημα προς owner + G4.
2. **Auto-match ΝΕΚΡΟ, επιβεβαιωμένο:** 0/1.157 locations με συντεταγμένες
   (μέτρηση live) → μέγιστο score 30 (ημερομηνία) < κατώφλι 40 → καμία πρόταση,
   ποτέ. Δένει με LO-1.
3. **KPI «ΚΕΝΑ ΔΡΟΜΟΛΟΓΙΑ» αναξιόπιστο, μετρημένο:** δείχνει 10 όταν τα
   πραγματικά αταίριαστα σκέλη είναι 36 (W20). Το string-heuristic 3 γραμμάτων
   υπο-μετρά ×3.6, ενώ τα σωστά νούμερα υπάρχουν ήδη υπολογισμένα στη σελίδα.
4. **`Assigned At` άχρηστο για τις ιστορικές εβδομάδες:** 43/50 σφραγίδες είναι
   ΜΕΤΑ τη φόρτωση — το πεδίο προστέθηκε αργότερα και σφραγίστηκε αναδρομικά.
   Ο «χρόνος κλειδώματος» μετριέται αξιόπιστα μόνο από εδώ και πέρα (W32+).
5. **`createdTime` δεν επιστρέφεται από τον Worker** (0/97 records) — η μέτρηση
   «αργές είσοδοι vs cutoff Τετάρτης» είναι αδύνατη από το app σήμερα.
6. **On-time 15/96 (16%) στα καταγεγραμμένα** — είτε πρόβλημα καταχώρησης του
   `Actual Delivery Date` (βλ. και DO-10: το κουμπί έγραφε `Delayed`) είτε
   πραγματικότητα. Πριν στηθεί οτιδήποτε πάνω στο KPI ΣΥΝΕΠΕΙΑΣ, θέλει απάντηση.
7. **Το groupage δεν αφήνει ίχνος:** γίνεται 1-3×/εβδομάδα (00 §5) αλλά στα
   δεδομένα φαίνεται 0-1 φορές — η ομάδα ζει μόνο στη μνήμη της σελίδας και
   χάνεται, άρα ούτε ιστορικό, ούτε εκτύπωση ομάδας, ούτε μέτρηση.
8. **Μείγμα στόλου ασταθές ανά εβδομάδα** (own/partner: 10/7 → 19/4 → 4/6) —
   η απόφαση «δικό μας ή συνεργάτης» παίρνεται κάθε εβδομάδα από την αρχή,
   χωρίς το σύστημα να δείχνει διαθεσιμότητα ή ιστορικό τιμών (00 §3-4).
