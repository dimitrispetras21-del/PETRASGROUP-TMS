# Σήμερα ↔ σχέδιο: επιχειρησιακός έλεγχος (owner 15/11/2026)

> «ο πραγματικός έλεγχος θα γίνει και από business οπτική: αν είναι όλα τα κουμπιά σωστά, αν κάτι έχει ξεχαστεί»

Τρεις ανεξάρτητοι έλεγχοι διάβασαν τον κώδικα της σημερινής εφαρμογής, κουμπί προς κουμπί, και τον σύγκριναν με το σχέδιο. Τα πλήρη φύλλα, με `αρχείο:γραμμή` για κάθε γραμμή:
[Παραγγελίες](audit-orders.md) · [Εβδομαδιαίο Εθνικών](audit-weekly-national.md) · [Έξοδα δρομολογίων](audit-expenses.md). Η φόρμα διεθνούς ελέγχθηκε απευθείας πάνω στο `modules/orders_intl.js`.

Τι **δεν** ελέγχθηκε: η ζωντανή εφαρμογή, η βάση, ο Worker που τρέχει. Όλα είναι από ανάγνωση κώδικα.

## Νέα διεθνής παραγγελία

| Τι έλειπε | Τώρα στο σχέδιο |
|---|---|
| Ανταλλαγή παλετών ανά σημείο φόρτωσης και ανά σημείο παράδοσης | κουτάκι και αριθμός σε κάθε σημείο· ο γενικός διακόπτης πάνω |
| «Μέσω Βέροιας» ανά σημείο | κουτάκι μόνο στην εθνική πλευρά |
| Ώρες ανά σημείο, αφαίρεση σημείου | «όλη η ημέρα» όταν είναι κενό· × σε κάθε σημείο εκτός του πρώτου |
| Θερμοκρασία «κατά CMR», ψυκτικό, τύπος παλέτας, βάρος | υπάρχουν |
| «Σε απόθεμα», «Υψηλό ρίσκο», «Αποθήκευση και νέα» | υπάρχουν |
| **Δεν σχεδιάστηκαν ακόμη** | επεξεργασία (με «Διπλασιασμός»), κομμάτι από απόθεμα με χρέωση αποθήκης, ουρά σάρωσης με «Παράλειψη» |

## Παραγγελίες (λίστα και κάρτα)

| Τι έλειπε ή ήταν λάθος | Τώρα στο σχέδιο |
|---|---|
| Αριθμός παραγγελίας | δίπλα στο όνομα στην κάρτα, και στο ποντίκι πάνω από τη γραμμή |
| «Εκτός Εβδομαδιαίου» με «Στείλε →» | κόκκινο πλακίδιο στη γραμμή, σκούρο κουτί στην κάρτα |
| Pre-order | γραμμή με «PRE», «Μετατροπή σε παραγγελία», τρίτη επιλογή στο «Νέα παραγγελία» |
| «Ακυρώθηκε» | διαγραμμένη λέξη, τιμή και ανάθεση «–» |
| ΤΠΥ «εκκρεμεί» (δεν υπάρχει σήμερα, και έδειχνε παλιό κανόνα) | βγήκε· μπήκε η αυτοπαράδοση ως ✓ και η ημερομηνία ΤΠΥ στο ποντίκι |
| Οδηγός με αρχικό + επώνυμο (δύο οδηγοί έχουν ίδιο επώνυμο) | πλήρες όνομα |
| Συνεργάτης: πάντα η λέξη «συνεργάτης» | οι πινακίδες του |
| Όλα τα σημεία στην κάρτα, με παλέτες ανά σημείο | υπάρχουν |
| Βήμα Βέροιας «Αλλαγή φορτηγού»· ημέρα πάντα φόρτωση + 1 | «Cross-dock» με το εθνικό σκέλος· εισαγωγή = παράδοση − 1 |
| Βάρος σε τόνους, θερμοκρασία χωρίς «CMR» | κιλά· «CMR» |
| Έγγραφα και «Αντίγραφο» σε εθνική (δεν υπάρχουν σήμερα) | μόνο στις διεθνείς· λέξη «Διπλασιασμός» |
| «Ανάθεση στο Εβδομαδιαίο» (από την κάρτα δεν γίνεται ανάθεση) | «Άνοιγμα στο Εβδομαδιαίο» |
| Φίλτρο «Μάρκα», «Χωρίς τιμή» στον κατάλογο, αριθμός στο μενού | υπάρχουν |
| Αξία περιόδου χωρίς την υποσημείωση | κυκλάκι: «10 χωρίς τιμή δεν μετρούν» |
| Μενού κεφαλίδας, «Διόρθωση» του λογιστηρίου, κάρτα μόνο για ανάγνωση | νέο μπλοκ «Ό,τι ανοίγει από τη σελίδα» |
| Συνδετήρας εγγράφων, «HR», δελτίο παλετών που εκκρεμεί | σημάδια στη γραμμή και στην κάρτα |
| **Δεν σχεδιάστηκαν ακόμη** | παρτίδα αποθήκης και κομμάτι (`ΑΠ`, «Στην αποθήκη»), «μέσω ομαδοπ.», «2 σκέλη», μάρκα πάνω στην κάρτα, «Μεταφορέας», «Καθαρισμός», ταξινόμηση σε κάθε στήλη |

**Καινούρια στο σχέδιο, αποφασίζεις εσύ:** κατάσταση με λέξη στις εθνικές (σήμερα δεν γράφεται, δείχνει «—»)· μία κάρτα για διεθνείς και εθνικές (σήμερα δύο)· «Όλες 380» ως κουμπί.

## Εβδομαδιαίο Εθνικών

| Τι έλειπε ή ήταν λάθος | Τώρα στο σχέδιο |
|---|---|
| Μενού φορτίου χωρίς φορτηγό | «Καρτέλα παραγγελίας», «Ανάθεση», «Στον Πίνακα Βέροιας», «Διαγραφή παραγγελίας» |
| Δεξί κλικ σε σημείο | «Μεταφορά σε άλλο φορτηγό», «Αλλαγή στον δρόμο από εδώ», «Διαγραφή σημείου», «Διαγραφή παραγγελίας» |
| Μενού φορτηγού: ποιο φορτηγό, επιλογή Κάθοδος / Άνοδος, «ή συνεργάτη» | κεφαλίδα με φορτηγό και ημέρα, βελάκι στις τέσσερις γραμμές, διαχωριστικό πριν το κόκκινο |
| Ημέρα και ώρες: μόνο ένα σημείο, «Εντάξει» | όλη η πλευρά, «Τι αλλάζει» ανά σημείο, «Και η άνοδος +1», προειδοποίηση οδηγού, «Αποθήκευση» |
| «ΕΠΟΜΕΝΑ» με φορτία που δεν ήταν γραμμές· ονόματα πελατών | κάθε φορτίο είναι και γραμμή στην ημέρα του· ονόματα τόπων |
| Άγνωστες παλέτες | «14+;» με διακεκομμένη μπάρα, ποτέ σαν γεμάτο |
| «χωρίς οδηγό», «λείπει τιμή», φόρτωση με τοπικό | σημάδια πάνω στη γραμμή |
| Η Βέροια σε άλλη ημέρα στο Διεθνών | «VS Τρί 17» δίπλα στη Βέροια |
| Απόθεμα Βέροιας | στο κουμπί «Βέροια» |
| «Αποθηκεύτηκε, η οθόνη είναι παλιά», «Άγνωστο αν γράφτηκε», «Διαβάστηκε το μισό», εβδομάδα πριν τη μετάβαση | τέσσερις νέες «κακές στιγμές» |
| **Δεν σχεδιάστηκαν ακόμη** | επόμενο φορτίο με το ίδιο φορτηγό ως δεύτερη γραμμή· λίστα «ΤΟΠΙΚΑ» οδηγός × ημέρα· φορτηγό γειτονικής εβδομάδας· κλείσιμο ημέρας· κάθε τμήμα της αλλαγής οχήματος με οδηγό και κόμιστρο· «Μόνο κάθοδος · συνεργάτης»· «σε πρόχειρο»· «Όλες οι N» στα Επόμενα |

**Καινούρια στο σχέδιο, αποφασίζεις εσύ:**

1. Σημάδια στην κεφαλίδα της ημέρας (φορτηγά, χωρίς φορτηγό, γυρίζει άδειο, πάνω από 33). Στις 31/10 έβγαλες τις μετρήσεις από την κεφαλίδα.
2. «Σύνθεση φορτίων» και «Βέροια» μαζί, για όλους. Σήμερα φαίνεται το ένα ή το άλλο, και η Σύνθεση είναι δοκιμαστική.
3. Μπάρα γεμίσματος κάτω από τις παλέτες.
4. Περασμένες ημέρες ξεθωριασμένες με βάση την ημερομηνία. Σήμερα ξεθωριάζει ό,τι η βάση λέει «έγινε», ποτέ γραμμή που θέλει δουλειά.
5. Το κενό γύρισμα λέει και τον τόπο όπου ελευθερώνεται το φορτηγό.
6. Αναζήτηση που προτείνει αποτελέσματα σε άλλες εβδομάδες.
7. «Μόνο ανάγνωση» σε αυτόν τον πίνακα: σήμερα όλοι βλέπουν όλα τα κουμπιά (δική σου απόφαση).

## Έξοδα δρομολογίων

| Τι έλειπε ή ήταν λάθος | Τώρα στο σχέδιο |
|---|---|
| «Θέλουν ματιά» με δικό μου κανόνα | ο σημερινός: τελείωσε και δεν έχει καύσιμα ή διόδια |
| Γραμμές DKV χωρίς δρομολόγιο εκτός συνόλου | μετρούν στο σύνολο της εβδομάδας, όπως σήμερα· δική τους γραμμή στο χαρτί |
| Λόγος σε κάθε διόρθωση, σβήσιμο, ταίριασμα | υποχρεωτικό πεδίο «Λόγος» |
| Γραμμές DKV κλειδωμένες | λουκέτο· αλλάζουν μόνο κατηγορία, χώρα, δρομολόγιο |
| Τρόπος πληρωμής ανά γραμμή (DKV, Μετρητά, Revolut, Πίστωση) | ετικέτα σε κάθε γραμμή |
| Μετρητά οδηγού από τη Μισθοδοσία | κλειδωμένη γραμμή |
| Καταχώρηση: κατηγορία, πληρωμή, χώρα, ημέρα, λίτρα, χιλιόμετρα, πρατήριο | πλήρης γραμμή καταχώρησης |
| Ταίριασμα χωρίς πινακίδα | πινακίδα, και το δρομολόγιο που ταιριάζει ως κουμπί |

**Καινούρια στο σχέδιο, αποφασίζεις εσύ:** σημάδι «ίσως διπλό»· τρεις ομάδες (Θέλουν ματιά, Σε εξέλιξη, Πλήρη)· «Επόμενο»· το χαρτί Α4.

**Τρία ευρήματα στη σημερινή σελίδα (από κώδικα, δεν μετρήθηκαν σε δεδομένα):**

1. Τα μετρητά του οδηγού ίσως μετριούνται δύο φορές στα σύνολα: μία ως γραμμή εξόδου με πληρωμή «Μετρητά» και μία από τη Μισθοδοσία.
2. Τα εθνικά δρομολόγια του νέου πίνακα δεν γίνονται ποτέ «κλειστά», άρα δεν βγαίνουν ποτέ στο «θέλει ματιά».
3. Το ταίριασμα γραμμών χωρίς δρομολόγιο δεν δείχνει πινακίδα, δείχνει μόνο την εβδομάδα που κοιτάς, και διαβάζει τις πρώτες 300.
