# Διάγραμμα διαδρομής · ένα κοινό κομμάτι για τρεις οθόνες (8/11/2026)

**Owner 8/11:** «το feature με το διάγραμμα» σε τρεις οθόνες: Εβδομαδιαίο Εθνικών v5, πάνελ παραγγελίας της
«Παραγγελίες › Εβδομάδα», πάνελ της «Παλέτες › Εβδομάδα». «Το διάγραμμα» = η κάθετη διαδρομή της καρτέλας «Διαδρομή»
του πάνελ (Figma `2283:10009`). Και: «έχουμε σχεδιάσει και ετοιμάσει όλες τις δυνατές περιπτώσεις». Άρα **κανένα νέο
σχέδιο**: ό,τι ζωγραφίζεται εδώ βγαίνει από τα `docs/order-route/CASES.md`, `RT-CASES.md`, `PANEL.md`, `ROUTE-GRAMMAR.md`
και τις κάρτες «στυλ πάνελ» `2310:7917`–`2310:7926`.

**Κατάσταση:** μόνο τα νέα αρχεία του κομματιού, τα tests και η σελίδα προεπισκόπησης. **Καμία** οθόνη δεν το καλεί ακόμη,
κανένα `app.html` / `sw.js` / `config.js` δεν άλλαξε, τίποτα στη βάση ή στον Worker.

## 1 · Το κομμάτι (API)

| Αρχείο | Τι κάνει |
|---|---|
| `core/route-diagram.js` (`window.RouteDiagram`) | `build(input) → model`, `html(model) → string`, `render(input)`. Καθαρές συναρτήσεις: κανένα fetch, κανένα DOM, το «σήμερα» είναι όρισμα. |
| `core/route-diagram-adapters.js` (`window.RouteDiagramAdapters`) | Ένας προσαρμογέας ανά πηγή: `boardCycle(cycle, ctx)`, `facadeOrder(rec, stops, ctx)`, `facadeRt(items, ctx)`, `natLegFromBoard(boards, orderPgId)`. |
| `assets/route-diagram.css` | Κλάσεις `rd-*`. Χρώματα από τα tokens του `assets/style.css` όπου υπάρχουν. |
| `tests/route-diagram.test.js` · `tests/fixtures/route-diagram-cases.js` | 32 tests. Η λίστα περιπτώσεων είναι **μία**, για τα tests και για τη σελίδα. |
| `tests/critics/route-diagram-preview.html` | Όλες οι περιπτώσεις δίπλα-δίπλα (`file://`). Με `?fid=RT1` ζωγραφίζει μόνο το frame του Figma, στα 440. |

Ο οικοδεσπότης γράφει **μία γραμμή**: `el.innerHTML = RouteDiagram.render(RouteDiagramAdapters.boardCycle(cycle, ctx))`.

**Είσοδος** (`input`): `{ today, sections: [{ title, chip?, aside?, done?, rows: [...], executor? | executors? }], kv?, empty? }`.
Γραμμές:
- `stop`: `act` load / unload / both, `day`, `time?`, `dayTo?`, `name`, `city?`, `cc?`, `pallets?`, `extra?`, `marked`, `assigned`,
  `late`, `overlap`, `seg?` (ΑΡΧΙΚΟ / ΕΝΔΙΑΜΕΣΟ / ΤΕΛΙΚΟ) ή `tag?` (π.χ. «ΕΘΝΙΚΟ ΦΟΡΤΗΓΟ 2»), `notes?`.
- `crossdock`: η Βέροια ως κόμβος VS.
- `node`: `warehouse-leave` / `warehouse-pick`, `customs`, `border`, `stock-out` / `stock-in`.
- `handover`: ⇄, με `what` vehicle / transship / driver, `place`, `from` → `to` τμήμα, `reason`.

**Μοντέλο:** τμήματα → γραμμές `{ kind: stop | crossdock | node | handover | executor, dot, label, flag, tag, dayText,
dayTone, name, meta[], notes[], line }`.

**Κανόνες** (από δεδομένα, ποτέ με το χέρι):
- **Κουκκίδα στάσης:** `assigned === false` → διακεκομμένος κόκκινος κύκλος · `late` → κόκκινος + «καθυστέρηση» ·
  `marked` → γκρι · χωρίς ημέρα → «χωρίς ημέρα» · ημέρα πριν από σήμερα χωρίς σήμανση → κόκκινος + «δεν σημειώθηκε» ·
  σήμερα → μπλε · μετά → λευκός.
- **Cross-dock:** μπλε όταν είναι σήμερα, αλλιώς πορτοκαλί κόμβος, με «όριο» μετά τις παλέτες.
- **Χώρα:** `cc === null` → κόκκινο «χώρα;» (N2), ποτέ μαντεμένο GR. `cc` απών = δεν ζητήθηκε, άρα δεν τυπώνεται.
- **Παλέτες:** `null` → «;π» (F1/F4), ποτέ 0.
- **Γραμμή:** από κάθε σημείο στο επόμενο του ίδιου τμήματος· το τελευταίο σημείο δεν έχει γραμμή.
- **Λάθος είσοδος σταματά** (`InputError`), ποτέ κενή γραμμή.

## 4 · Ανά οθόνη: προσαρμογέας και αναγνώσεις (κανόνας «front end ως τον πίνακα»)

Το διάγραμμα **μόνο διαβάζει**. Καμία ενέργεια, κανένα νέο endpoint.

**Εβδομαδιαίο Εθνικών v5 (`modules/weekly_natl_v5.js`):** `boardCycle(cycle, ctx)`.
- Πηγή: το board που έχει ήδη φορτώσει η οθόνη, `GET /plan/board?week=` (072 `plan_board` + 072b).
  - Πίνακες: `ct_round_trips` (model 2), `rt_stops`, `piece_legs`, `rt_vehicle_segments`, όψη `v_rt_stop_state`.
  - Στήλες: `executed`, `has_vehicle`, `has_late`, `stop_day`, `planned_from` / `planned_to`, `side`, `location_id`, `location`,
    `legs[].kind` / `act` / `pallets` / `order_id`, `segments[].label` / `stop_ids` / `from_at` / `place_note` / `reason`.
- Τμήματα και ⇄ από `WN5L.stopSegments` / `WN5L.handoversOf`, ο λόγος από `WN5Lab.reasonLine`. **Κανένα αντίγραφο κανόνα**:
  ένα test σπάει τον `handoversOf` και η ⇄ χάνεται.
- Χώρα και πόλη: το board δεν τις έχει.
  - `ctx.cityOf` / `ctx.countryOf` = `PlanIds` (`GET /plan/lookups`, 074a `plan_lookups`: `locations.id` → `legacy_id`, `city`)
    → `OrdersCommon._locMeta(legacy_id).cc`.
  - Αυτό είναι το facade LOCATIONS `Country` → `locations.country`, ήδη στο reference data.
  - Χωρίς Worker.
- Αποτυχία: χωρίς board η οθόνη δεν έχει κύκλο να ανοίξει (ήδη λωρίδα). Χωρίς lookups το `countryOf` δεν δίνεται, άρα η
  χώρα **δεν τυπώνεται**. Ποτέ «χώρα;» από αποτυχία ανάγνωσης.

**«Παραγγελίες › Εβδομάδα» (`modules/orders_week_view.js`), πάνελ παραγγελίας:** `facadeOrder(rec, stops, ctx)`.
Για γραμμή RT: `facadeRt(items, ctx)`.
- ORDERS: ήδη στο `load()`. Facade `tblgHlNmLBH3JTdIM` → `orders`, πεδία `Order No`, `Direction`, `Veroia Switch`, `Truck`,
  `Partner`, `Status`, `Pallet Exchange`, `Parent Order`. Τα σκέλη σπασίματος είναι ήδη στο ίδιο παράθυρο (`isSplitLeg`).
- ORDER STOPS: **χρειάζεται διεύρυνση της υπάρχουσας ανάγνωσης.**
  - Σήμερα διαβάζει μόνο `Parent Order`, `Stop Type`, `DateTime`, `Location` (γρ. 804).
  - Θέλει και `Pallets`, `Completed At`, `Stop Number` → `order_stops.pallets`, `completed_at`, `stop_number`.
  - Είναι **ήδη** στον χάρτη του Worker (test που το ελέγχει, παγίδα facade 1). Μόνο front end.
- LOCATIONS: `OrdersCommon._locMeta` (reference data, `Name` / `City` / `Country`).
- Σειρά των παραγγελιών ενός RT: `/costs/rt?overlap=1` (ήδη: `ct_round_trips` + `ct_rt_legs`).
- Εθνικό σκέλος VS: `natLegFromBoard(d.v5Board / v5Earlier, pgIdOf(rec))`.
  - Το board διαβάζεται ήδη όταν η οθόνη δείχνει εθνικά.
  - Πριν από την ημέρα L ή με φίλτρο «Διεθνή» δεν υπάρχει board. Τότε `natLeg` λείπει και το τμήμα λέει κόκκινο
    «εκτελεστής: δεν διαβάστηκε», ποτέ «χωρίς ανάθεση».
- Θέση: η κάρτα παραγγελίας είναι του `orders_intl.js` (`openIntlCardWith`, ενότητα «Διαδρομή», γρ. 469). Αλλαγή κοινού
  αρχείου με τον «Κατάλογο».

**«Παλέτες › Εβδομάδα» (`modules/pallets_week.js`), πάνελ N28 (`panelHtml`):** ο ίδιος `facadeOrder`, με το ίδιο ORDERS του

## 7 · Ερωτήσεις owner (πρόταση πρώτη)

1. **Πού μπαίνει στην «Παραγγελίες › Εβδομάδα»:**
   - Πρόταση: στην ενότητα «Διαδρομή» της κάρτας παραγγελίας, όταν ανοίγει από την εβδομάδα, στη θέση της σημερινής λίστας
     στάσεων.
   - Εναλλακτικά: κλικ στη γραμμή RT ανοίγει πάνελ με όλο το RT (`facadeRt`, όπως το frame `2283:10009`).
2. **Μπάρα για «όχημα πελάτη» (Δ20) και «τοπικός οδηγός» (Π8):** δεν σχεδιάστηκαν.
   - Πρόταση: τοπικός = navy (δικός μας)· πελάτης = ήσυχο γκρι περίγραμμα.
   - Ή να γίνουν πρώτα στο Figma.
3. **Οι κόμβοι που ζουν μόνο στις σημειώσεις** (αποθήκη τρίτου, τελωνείο, σύνορα):
   - Πρόταση: πρώτα το διάγραμμα με ό,τι γράφει η βάση, και μετά απόφαση για νέους τύπους στάσης (§5.1).
   - Ή regex στις σημειώσεις από τώρα.
