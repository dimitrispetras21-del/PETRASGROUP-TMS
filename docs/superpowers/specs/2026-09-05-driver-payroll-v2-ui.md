## Κανόνες λέξεων (ο λόγος που απορρίφθηκε η v1)
1. **Καμία** λέξη «του χρωστάμε / μας χρωστά / τακτοποιημένο» δίπλα σε ποσά. Το ποσό
   μόνο του: θετικό = οφειλή προς οδηγό, αρνητικό = **σε παρένθεση** `(95,20 €)` και amber.
   Μηδέν = `0,00 €` (πραγματικό μηδέν) ή `—` αν όλες οι γραμμές είναι χωρίς αξία.
2. **Κανένας** εσωτερικός κωδικός στην οθόνη: όχι `RT-1014`, όχι «τρέφει το TRIP PnL»,
   όχι «πηγή: dl_v_balance», όχι «χωρίς σύνδεση RT». Η σύνδεση με round trip μένει στα
   δεδομένα (`rt_id`) και εμφανίζεται μόνο ως μικρό εικονίδιο-σύνδεσμος, χωρίς κείμενο.
3. Μία δευτερεύουσα γραμμή ανά στοιχείο, το πολύ: «2 δρομολόγια · τελευταίο 29/08» ή
   «χωρίς κίνηση 39 ημέρες» ή «1 δρομολόγιο χωρίς αξία».
4. Σφάλμα φόρτωσης = «Δεν φορτώθηκε» + ξαναδοκίμασε (`showError`)· κενό = «Καμία κίνηση
   ακόμη» (`showEmpty`).

## Οθόνη 1 — Αρχική (route `payroll`, view `home`)
```
Header  : «Μισθοδοσία Οδηγών» (Syne 28) · [Μαζική πληρωμή] [Δρομολόγιο]
Strip   : 9.412 € οφειλή σήμερα · 64 δρομολόγια μήνα · 17 χωρίς αξία · 21.480 € πληρωμές μήνα · <μήνας>
Body    : αριστερά λίστα 460px (αναζήτηση, γραμμές 48px: αρχικά σε κύκλο, όνομα, ποσό)
          δεξιά ο επιλεγμένος οδηγός: hero (αρχικά 56px, όνομα Syne 24, «Εσωτερικός · N
          δρομολόγια φέτος», ΟΦΕΙΛΗ 28px), 3 μικρά κουτιά (ΑΞΙΑ έτους · ΠΛΗΡΩΜΕΣ έτους ·
          ΤΕΛΕΥΤΑΙΟ), πίνακας 7 τελευταίων κινήσεων (ΗΜ/ΝΙΑ · ΔΡΟΜΟΛΟΓΙΟ · ΑΞΙΑ · ΕΛΑΒΕ ·
          ΕΞΟΔΑ · ΣΥΝΟΛΟ), «Άνοιγμα καρτέλας →»
```
- Δεδομένα strip από `GET /costs/ledger` (records): οφειλή = Σ balance (active ≠ false)·
  «χωρίς αξία» = Σ pending_count· «δρομολόγια φέτος» = Σ trips_ytd. Οι «πληρωμές μήνα»
  **δεν** υπάρχουν στο endpoint — παράλειψέ τες (τρία νούμερα + μήνας), μην επινοήσεις.
- Λίστα: προεπιλογή «με κίνηση» (has_entries) ταξινομημένη κατά οφειλή φθίνουσα· από κάτω,
  αχνά, οι υπόλοιποι (χωρίς ποσό). Αναζήτηση φιλτράρει και τα δύο. Η επιλεγμένη γραμμή
  έχει αριστερή μπλε ράβδο 3px και φόντο `--surface-sunken`.
- Κλικ σε οδηγό → δεξί πάνελ (fetch `GET /costs/ledger/:id`, 7 τελευταίες ζωντανές
  κινήσεις), χωρίς αλλαγή route. Πρώτος οδηγός με κίνηση προεπιλεγμένος.
- «Άνοιγμα καρτέλας →» → οθόνη 2.

## Οθόνη 2 — Καρτέλα οδηγού (view `driver`)
```
← Μισθοδοσία
Hero    : αρχικά · όνομα Syne 28 · «Εσωτερικός · από <πρώτη κίνηση>» · ΟΦΕΙΛΗ 28px ·
          ΔΡΟΜΟΛΟΓΙΑ <έτος> · ΑΞΙΑ <έτος> · ΠΛΗΡΩΜΕΣ <έτος> · [Πληρωμή] [Δρομολόγιο]
Πίνακας : ΗΜ/ΝΙΑ · ΔΡΟΜΟΛΟΓΙΟ · ΑΞΙΑ · ΕΛΑΒΕ · ΕΞΟΔΑ · ΥΠΟΛΟΙΠΟ · ΣΥΝΟΛΟ  (γραμμές 44px)
          1η γραμμή = ΓΡΑΜΜΗ ΓΡΗΓΟΡΗΣ ΚΑΤΑΧΩΡΙΣΗΣ (φόντο sunken): ημερομηνία (σήμερα),
          διαδρομή (input), αξία, έλαβε, έξοδα (inputs) · Enter = POST trip · Esc = καθαρισμός
```
- Πληρωμές: αχνή γραμμή, «Κατάθεση τράπεζας» / «Μετρητά» στη στήλη ΔΡΟΜΟΛΟΓΙΟ, ποσό στη
  στήλη ΕΛΑΒΕ, `−ποσό` στο ΥΠΟΛΟΙΠΟ.
- Δρομολόγιο χωρίς αξία: ΑΞΙΑ `—` (amber), ΥΠΟΛΟΙΠΟ `—`.
- Ακυρωμένη: διαγράμμιση, αχνή, χωρίς ποσά· η αιτία σε `title`, όχι σε κείμενο.
- Κλικ σε γραμμή δρομολογίου → τα κελιά ΑΞΙΑ/ΕΛΑΒΕ/ΕΞΟΔΑ γίνονται inputs στη θέση τους
  (inline edit), Enter = PATCH (prompt αιτιολογίας ΜΟΝΟ αν αλλάζει γραμμένο ποσό — ο
  Worker το απαιτεί), Esc = άκυρο. Δεξί άκρο γραμμής: «×» για ακύρωση με αιτιολογία
  (prompt). Καμία μεγάλη modal φόρμα για δρομολόγια.
- [Πληρωμή] → μικρό modal: Ημερομηνία · Τρόπος (Τράπεζα/Μετρητά segmented) · Ποσό ·
  Καταχώριση. [Δρομολόγιο] = εστίαση στη γραμμή γρήγορης καταχώρισης.
- Chips έτους δεξιά πάνω από τον πίνακα (τρέχον, −1, −2, Όλα), προεπιλογή τρέχον.

## Οθόνη 3 — Μαζική πληρωμή (view `bulk`)
```
← Μισθοδοσία   «Μαζική πληρωμή»
Ημερομηνία · Τρόπος (Τράπεζα/Μετρητά) · Προσυμπλήρωση: [Ίδιο ποσό σε όλους] [Όλη η οφειλή] [Όπως τον προηγούμενο μήνα]
Πίνακας: ΟΔΗΓΟΣ · ΟΦΕΙΛΗ · ΠΡΟΗΓ. ΜΗΝΑΣ · ΠΟΣΟ (input) · ΝΕΑ ΟΦΕΙΛΗ · «παράλειψη» αν κενό
Footer : «N πληρωμές  6.098,17 €  τράπεζα · 13/09/2026»  [Άκυρο] [Καταχώριση N πληρωμών]
```
- Οδηγοί: όσοι έχουν has_entries, κατά οφειλή φθίνουσα.
- ΠΡΟΗΓ. ΜΗΝΑΣ: ποσό της τελευταίας πληρωμής ίδιου τρόπου (από `GET /costs/ledger/:id`,
  φόρτωση παράλληλη μόνο για οδηγούς με οφειλή > 0· αλλιώς `—`).
- «Ίδιο ποσό σε όλους» → prompt ποσού· «Όλη η οφειλή» → ποσό = οφειλή όπου > 0· «Όπως τον
  προηγούμενο μήνα» → ποσό = ΠΡΟΗΓ. ΜΗΝΑΣ όπου υπάρχει.
- ΝΕΑ ΟΦΕΙΛΗ = οφειλή − ποσό, ζωντανά· 0,00 πράσινο.
- Καταχώριση: ένα `POST /costs/ledger` ανά γραμμή με ποσό (`entry_type` payment_bank |
  payment_cash, `entry_date`, `amount`), σειριακά, με ένδειξη «k / N». Αν ένα αποτύχει:
  σταματά, δείχνει ποιος και γιατί, τα προηγούμενα ΜΕΝΟΥΝ (είναι πραγματικές πληρωμές) και
  η γραμμή τους δείχνει ✓. Τέλος: επιστροφή στην αρχική με ανανέωση.
- Αργότερα (όχι τώρα): upload/scan Excel κατάστασης τράπεζας που προσυμπληρώνει τα ποσά.
