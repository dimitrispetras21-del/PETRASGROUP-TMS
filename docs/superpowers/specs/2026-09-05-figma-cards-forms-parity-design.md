## 4. Σχεδίαση της αλλαγής

**Αρχή:** μία κοινή διόρθωση στο «περίβλημα», όχι έξι αντίγραφα (αρχή 3: δύο
πηγές αλήθειας = καμία). Το σώμα των καρτελών **δεν** αγγίζεται — ταιριάζει.

Καρτέλες οντοτήτων (`.ecard-head`, `_renderEntityCardV2`):
1. Κεφαλίδα navy (`--surface-dark`), τίτλος `--panel-text`, υπότιτλος `--panel-dim`.
2. Δεύτερη σειρά: status pill + type pill + meta, όπως στο Figma.
3. **Καμία λειτουργία δεν χάνεται**: μολύβι επεξεργασίας, toggle ενεργού, ✕ —
   αλλάζουν στυλ για σκούρο φόντο. Το toggle γίνεται το ίδιο το status pill
   (ένας δείκτης, όχι δύο — audit 29/8).
4. Τίτλος: μέχρι 2 γραμμές, ποτέ ellipsis σε 1 (κανόνας #6).

Φόρμες (κοινά `openModal`, `.modal-footer`):
5. Υποσέλιδο γκρι ζώνη (`--surface-sunken`), Ακύρωση ως link — **μόνο** μέσα σε `.modal-footer`.
6. Chip ονόματος: νέα προαιρετική 4η παράμετρος `openModal(title, body, footer, chip)`.
7. `cols: 3` ανά section στο `ENTITY_CONFIG` για Χώρα/Πόλη/Διεύθυνση (πελάτες) και
   Μάρκα/Μοντέλο/Έτος (φορτηγά, ρυμούλκες). Οι συνεργάτες ΟΧΙ: στο Figma 120:463 έχουν
   μόνο Χώρα + Διεύθυνση (δεν υπάρχει Πόλη) — διόρθωση διατύπωσης μετά την επαλήθευση.
8. `.btn-primary` (gradient) **δεν** αλλάζει — απόφαση εφαρμογής, όχι μονάδας.

Απορρίφθηκε: αντιγραφή του `.locc-head` σε κάθε module (τρίτο αντίγραφο του
ίδιου μοτίβου)· σβήσιμο του μολυβιού επειδή «δεν είναι στο Figma» (το Figma
δείχνει μία κατάσταση, ο κώδικας κρατά το συμβόλαιο).

## 5. Επαλήθευση

- Screenshots app ↔ Figma ανά οθόνη (rig: `shot.js` + HAR replay, cwd κύριο repo).
- `npm run critics` με `PW_BASE_URL` στον server κάθε worktree: συμβόλαιο
  `entity.json` (24 πεδία) και `locations.json` άθικτα, figma-map πράσινο.
- Ανεξάρτητος ελεγκτής (read-only) ξαναβγάζει screenshots από τους κλάδους και
  επιβεβαιώνει: navy κεφαλίδα, λευκός τίτλος, όλες οι ενέργειες παρούσες.
- Merge/deploy: **δεν γίνονται** σε αυτό το session (owner).

μετονομαστεί `_renderEntityCardV2`/`buildEntityModal` (θα προστεθούν στον
χάρτη). Οπτική παλινδρόμηση: τα PNG του session μένουν στο `docs/redesign/before`
