(782-807) → επανάληψη Opus αν φτωχό (orders_intl.js:2395-2417). Worker `/v1/ai/messages` με allowlist μοντέλων.

4. Οι διορθώσεις των στάσεων δεν μαθαίνονται· «διορθωμένο» παράδειγμα γράφεται σε κάθε αποθήκευση (orders_intl.js:2035-2052).

   διαβάζει πεδία εκτός χάρτη Worker (scan-helpers.js:431-458 vs worker 1771-1780) — να επαληθευτεί.
6. Δεν κρατιέται η έξοδος του AI → **η ακρίβεια δεν μετριέται σήμερα**.
7. `SCAN_MAX_TOKENS=4000` + Opus με thinking → κίνδυνος αποκοπής· `stop_reason` δεν ελέγχεται (scan-helpers.js:53).
8. Χωρίς structured outputs· cache_control σε λάθος μήνυμα (747-759) → ξαναπληρώνεται το έγγραφο ανά γύρο.
9. Λίστα αναφοράς = πρώτοι 50 πελάτες / 80 τοποθεσίες αλφαβητικά από ~1.920 (640-656).
10. Σχήμα χωρίς αποστολέα/παραλήπτη, διευθύνσεις, ώρες, refs ανά στάση, τύπο παλέτας, ADR, νόμισμα· 1 αρχείο = 1 παραγγελία.

## Σχέδιο 5 γύρων (σύνολο δοκιμής: 80–100 πραγματικές παραγγελίες 15 ημερών, 70% ανάπτυξη / 30% κρυφό)
1. **Μέτρηση πρώτα:** golden set στο `.local/scan-golden/` (gitignored), script μέτρησης, πίνακας `scan_runs` (migration → έγκριση).
2. **Νέα μηχανή:** μία κλήση με structured outputs, διευρυμένο σχήμα με βεβαιότητα + `source_quote` + σελίδα ανά πεδίο,
   `orders[]` (πολλές παραγγελίες ανά PDF), έλεγχος `stop_reason`. Στόχος +10 μονάδες σε κρίσιμα πεδία, 0 αποτυχίες JSON, p50 < 15s.
3. **Οθόνη ελέγχου + φύλαξη πρωτοτύπου:** έγγραφο δίπλα στη φόρμα, τονισμός πηγής, χρώμα βεβαιότητας, «αποδοχή βέβαιων»·
   πρωτότυπο σε ιδιωτικό bucket, συνδεδεμένο με την παραγγελία. Στόχος ≥ 60% χωρίς διόρθωση, 100% με πρωτότυπο.
4. **Αντιστοίχιση/διπλά/μάθηση:** pg_trgm στον server, ψευδώνυμα ανά πελάτη από διορθώσεις, παραδείγματα ανά πελάτη (έγγραφο→απάντηση),
   διπλό = ίδιο sha256 ή πελάτης+ref+ημ. φόρτωσης. Στόχος πελάτης ≥ 98%, τοποθεσίες ≥ 90%, 100% διπλών.
5. **Κανάλια:** .docx, επικόλληση email, .eml, θυρίδα προώθησης (Cloudflare Email Routing) → **μόνο προσχέδια**, ποτέ αυτόματη αποθήκευση.
Μετρικές: ακρίβεια ανά πεδίο (κανονικοποίηση, id για πελάτη/τοποθεσία), % εγγράφων με όλα τα κρίσιμα σωστά, βαθμονόμηση
(βεβαιότητα ≥ 0.9 → ≥ 98% σωστά), χρόνος/κόστος. Πύλη regression: πτώση > 1 μονάδα σε κρίσιμο πεδίο μπλοκάρει.
