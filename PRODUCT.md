# Product

## Register

product

## Users

Petras Group operations team, daily production use: dispatchers (weekly
planning, orders), warehouse/Veroia ramp staff, management, accountant
(Αλεξία — costs/invoicing), maintenance lead (Θοδωρής), owner (Dimitris).
Greek-speaking; desktop-first office use, some warehouse tablet use.

## Product Purpose

Transport Management System for an international cold-chain trucking company
(Greece ↔ EU). Runs the core loop: orders → weekly planning (intl + national)
→ assignment → ramp/cross-dock → invoicing → (soon) trip PnL. Success =
dispatchers plan a week without leaving the tool and the owner trusts the
numbers.

## Brand Personality

Cold-chain professional, operational calm, data-dense but legible.
"Refrigerated logistics control room": navy + Cold Chain Blue (#0284C7),
Syne (headings) + DM Sans (body). Dual brand: Petras Group / DPS Logistics.

## Anti-references

- Consumer-app playfulness; oversized marketing typography inside the tool.
- AI-slop dashboard grammar: side-stripe accent cards, gradient text,
  glassmorphism, hero-metric templates.
- Airtable/spreadsheet look — the TMS must feel like a product, not a grid.

## Design Principles

1. The tool disappears into the task — dispatchers live here for hours.
2. One vocabulary everywhere: same button, badge, table, modal on all pages.
3. State is color's only job: accent = action/selection; red/amber/green =
   money and risk semantics (loss/provisional/profit), never decoration.
4. Density with hierarchy — many rows, clear scanning order, no noise.
5. Every number a manager sees must be one click from its source (drill-down).

## Accessibility & Inclusion

Target WCAG AA. Known gaps: muted-text contrast, sparse ARIA, keyboard
support incomplete. Greek UI copy throughout; English only in code.
Reduced-motion support required (some coverage exists).
